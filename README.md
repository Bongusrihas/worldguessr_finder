# Streetview Capture

1. Open `chrome://extensions` and load this folder as an unpacked extension, or
   click **Reload** if it is already installed.
2. On the game page, click the extension's toolbar icon to open its side panel.
3. Reload that page or start a new round. The location appears in the map inside
   the panel. No separate Maps tab is opened.

Monitoring starts when the panel first connects. **Stop** pauses capture for
that page while leaving the current map visible. **Start** resumes capture of
new requests. Refreshing or reopening the panel preserves its Start/Stop state.
Each tab has independent controls.
